The goal of this project is to follow the idea created by "Automatic Chemical Design Using a Data-Driven Continuous Representation of Molecules", but for landscapes and diversity. Essentially, we want to optimize over landscapes for some kind of diversity metric. Our method for doing this is using a VAE to turn the landscape data, in this case a transtion matrix, into a continuous representation. We will also have some sort of model (like an MLP) going from the continuous latent space representation to a diversity target. At the beginning, this is a heterozygosity decay exponent. From there we can use gradient based optimization techniques on the continuous latent space representation to optimize for genetic diversity. By using a VAE, we will also be able to generate new landscapes.

Because our landscapes are transition matrices, I have been looking at graph neural networks as the general starting point for our design. These should have permutation invariance built in in some way. We can also build in extra tools so that it outputs a valid transition matrix everytime.
