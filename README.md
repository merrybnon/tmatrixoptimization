# tmatrixoptimization

Learning generative and predictive models of Markov transition matrices, and the relationship between a matrix's structure and the dynamics it produces.

Transition matrix data arrives from outside the repo. The `ingest` stage is the only code that reads the external drop; it validates and writes canonical arrays plus provenance to `data/processed/`, and everything downstream reads only from there.

## Layout

- `config/` — `sweeps/` (one YAML per sweep)
- `workflow/` — Snakemake pipeline: `Snakefile`, `rules/`, `profiles/`
- `src/tm_ml/` — the importable package the rules call
- `data/` — gitignored; `raw/` is the untouched external drop, `processed/` the ingest output
- `results/` — gitignored; autogenerated run directories
- `tests/` — with a committed tiny fixture so the pipeline runs without the real data
- `docs/` — `benchmarks/` and `notes/`
